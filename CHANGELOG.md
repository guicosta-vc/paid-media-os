# Changelog

## v0.2.0 — 2026-10-12

- Added machine-checkable tenant lifecycle, Strategy Lock, 50-concept bank, 3-5-concept selection, and production-asset gates before a Meta write.
- Bound every static, carousel, or video catalog asset to the exact Meta creative payload it is approved to use.
- Persisted durable write receipts before every POST; paused creation now stops on read-back scope or status mismatch.
- Added immutable-report reconciliation so decisions can use verified complete coverage without modifying the raw report.
- Added a complete portable-bundle installer and clarified that a single skill folder is not a runnable OS installation.
- Hardened release scanning to inspect staged Git blobs as well as untracked public-release candidates.
- Made contribution policy deterministic: external pull requests are not currently accepted until a published agreement and signature flow exist.
- Clarified paid productization policy, commercial-signing authority, security reporting, and environment-example wording.

## v0.1.0 — 2026-10-10

- Initial clean-room public draft under Business Source License 1.1.
- Added generic agent skills for strategy, creative selection, Meta operations, and reporting decisions.
- Added offline workspace validation, exact-account read support, report collection, approval-gated paused creation, and separate activation support.

No live Meta request has been made by this repository release process.
