# Design principles

Paid Media OS is intentionally generic and independently authored.

## Artifact before action

Every material action should have a durable input: strategy, concept, asset, manifest, approval, report, or decision record. Chat is not an execution ledger.

## Separate readiness, approval, execution, and proof

A campaign can be ready without being approved. It can be approved without being created. It can be created without being active. It is live only after exact read-back confirms the external state.

## One controlled first cell

A 50-concept bank creates options. It does not justify launching 50 creatives. The initial cell is 3-5 distinct hypotheses that can teach something under the available budget and audience.

## Evidence hierarchy

Platform delivery may be useful, but downstream quality matters more when it is available. A click is not a lead, a lead is not revenue, and an agent must not collapse those meanings.

## Least privilege

Each run should resolve one intended account, one manifest, one approval, and only the needed API operation. Credentials remain external to the repository and workspace artifacts.
